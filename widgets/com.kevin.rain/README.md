# Rain Widget
A precipitation nowcast + temperature trend for your location (Open‑Meteo, no key, via proxy). Big current temp + condition, a "Dry / Rain in ~Nh" verdict, and a 12‑hour chart (temperature line + rain‑chance bars).

Note: true weather‑radar map tiles can't render under the widget's content‑security policy (external image hosts are blocked), so this is a data‑based nowcast rather than a radar image. Settings: **latitude/longitude**, **units**.
