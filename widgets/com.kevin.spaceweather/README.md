# Space Weather Widget
Geomagnetic activity from NOAA SWPC: the current planetary **Kp index** (color‑coded quiet/unsettled/storm), a 24‑hour Kp history chart, and a rough **aurora** visibility read for your latitude. Self‑contained (proxy to `services.swpc.noaa.gov`, no key). Pairs with Sun Clock / Moon / ISS. Settings: **your latitude**.
