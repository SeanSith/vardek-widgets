# METAR Widget
Decoded aviation weather for the airports you list, with flight‑category color coding (VFR/MVFR/IFR/LIFR), temperature, wind, visibility, altimeter, dewpoint, and the raw METAR. Self‑contained (proxy to `aviationweather.gov`, no key). Settings: **airports** (ICAO codes, comma‑separated, up to 8), **temp units**.
